Chaithat's Project Space

tallad.co GitHub Website

A second-hand fashion marketplace with seller onboarding, Stripe Connect payments, item reservations, and real-time buyer-seller chat. I built the product end to end, including the backend logic needed to handle inventory and prevent double-sales.

Agentic RAG for Document Search GitHub

A document Q&A system built around hybrid retrieval and source-grounded answers. It uses parent-child chunking, vector and full-text search, reciprocal rank fusion, cross-encoder reranking, and a bounded agent loop that can reformulate queries and retrieve more evidence before answering.

Dell Technologies × NVIDIA Hackathon

Built a local AI agent on a Dell GB10 for the Dell × NVIDIA hackathon, using on-device inference and custom tools to work with private data. The stack was React, FastAPI, MongoDB, and vLLM.

vLLM / Llama Inference Experiments

Benchmarked Llama 3.1-8B with vLLM on NERSC Perlmutter across 1, 2, and 4 GPUs. Measured TTFT and TPOT, profiled runs with Nsight Systems, and experimented with scheduler settings to understand their impact on queueing and throughput.

AI for Cities: NYC Sanitation Digital Twin (In Progress)

A Cornell AI for Cities project focused on building a decision-support model for NYC's Empire Bins program. Our team is combining sanitation complaints, waste pressure, building eligibility, and street geometry to help compare areas for deployment.
